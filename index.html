DropIn Classics rebuilds the programs of classic DOS games as native programs for Windows, macOS, Linux and the Steam Deck. You bring the game you own; the port brings the code that runs it, with a double click and without an emulator.

What I aim for

Every port follows the same promises, on every platform and for every game.

01

Native, not emulated

The game's programs translated into readable C that runs directly on today's systems: no DOSBox, no configuration, no cycles to tune.

02

Your copy, open code

A port holds only its own code, open on GitHub. The game's data comes from the release you bought, read from it on your machine. Without it, nothing can be played.

03

Download, unpack, double click*

No installer and nothing else to install. The port finds your GOG release by itself on the first start.

04

The original, first

The game plays as it did. Each port is checked against the original program running in an emulated PC, byte for byte where it counts, and then played by me.

05

Better where it gets in the way

Controllers, a setup screen, full screen, shorter waits. Every change to the game's behaviour can be switched off again.

06

Open and quiet

The source and how each port was checked are on GitHub. A port looks for new versions** only if you say yes, and sends nothing.

  1. * On macOS, you will have to allow the app to run manually. You can thank Apple for that.
  2. ** There are no automatic updates: the port tells you that a new version is out, and you download it and put it in place of the old one yourself (on macOS, allowing it to run again).

Made by AI,
played by a human

The ports are reverse engineered and written entirely by AI agents (Claude, by Anthropic): they take the original programs apart, translate them into C and check the result against the original, step by step.

I choose the games, decide what the ports should do for the player and test them by playing them. If something plays differently from the original, tell me in the port's repository on GitHub.

Download Source and how it was made

  • Starts with a double click

    No emulator, no DOSBox configuration, nothing to install. On the first start it finds your GOG release by itself and copies the game's files.

  • A setup screen before the game

    In the look of a DOS setup program: start any of the eight tables straight away or go through the game's own menu, and set the options the game hides behind F10.

  • Game controllers

    Flippers, plunger and nudge on any controller SDL knows (XInput on Windows), each button assignable on the setup screen.

  • Less waiting, if you like

    Quality of life fixes, each switchable: skip the table animations, shorter silent pauses between balls and at the bonus count. Switched off, the game waits as the original did.

  • The tables as they were

    The table engine is translated routine by routine and compared byte for byte with the original running in an emulated PC, through whole games.

  • Sound and screen

    Volume, bass, treble and a headphone mode; full screen with Alt+Enter (Cmd+Enter on a Mac).

  • Your things stay yours

    Settings, saves and high scores live in your user folder: a new version replaces the program's folder and keeps them. It looks for new versions only if you say yes, fetches one small file and sends nothing.

You need: Pinball Dreams Deluxe from GOG.com.

Getting started

  1. Own the game

    Buy and install the game's release from GOG.com. The port reads its files; it does not replace them.

  2. Download the port

    Take the package for your system from the port's latest release and unpack it anywhere.

  3. Double click

    On the first start the port finds your copy and sets itself up. The README.txt in the package says what to do if your system asks about an unsigned program.
