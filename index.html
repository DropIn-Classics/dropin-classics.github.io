DropIn Classics makes native compatibility implementations of classic DOS games for Windows, macOS, Linux and the Steam Deck. You bring the game you own; the port brings its own code to run it, with a double click and without an emulator.

What I aim for

Every port follows the same promises, on every platform and for every game.

01

Native, not emulated

An independent implementation in readable C, made from analysis of the game's original programs and running directly on today's systems: no DOSBox, no configuration, no cycles to tune.

02

Your copy, open code

A port holds only its own code, open on GitHub. The game's data comes from the release you bought, read from it on your machine. Without it, nothing can be played.

03

Download, unpack, double click*

No installer and nothing else to install. The port finds your GOG release by itself on the first start.

04

The original, first

The game plays as it did. At critical points, each port's state and behaviour are compared with the original program running in an emulated PC, and then the port is played by me.

05

Better where it shows its age

Controllers, a setup screen, full screen, shorter waits. Every change to the game's behaviour can be switched off again.

06

Open and quiet

The source and how each port was checked are on GitHub. A port looks for new versions** only if you say yes, and sends nothing.

  1. * On macOS, you will have to allow the app to run manually. You can thank Apple for that.
  2. ** There are no automatic updates: the port tells you that a new version is out, and you download it and put it in place of the old one yourself (on macOS, allowing it to run again).

Made by AI,
played by a human

The ports are reverse engineered and written entirely by AI agents (Claude, by Anthropic): they analyse the original programs, reimplement their behaviour in C and compare the new implementations with the originals, step by step.

I choose the games, decide what the ports should do for the player and test them by playing them. If something plays differently from the original, tell me in the port's repository on GitHub.

The agents work with an open toolkit of their own, made for porting DOS games: what doskit is and why it exists.

Getting started

  1. Own the game

    Buy and install the game's release from GOG.com. The port reads its files; it does not replace them.

  2. Download the port

    Click your system's button at the port and unpack the package anywhere. A new release is a file few people have downloaded yet, so a browser may hold it back (Chrome calls it a dangerous or suspicious download): open the browser's list of downloads and keep it. The buttons fetch it from the port's release page on GitHub; take it from nowhere else.

  3. Double click

    On the first start the port finds your copy and sets itself up. The README.txt in the package says what to do if your system asks about an unsigned program.
